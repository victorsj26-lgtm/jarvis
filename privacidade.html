Política de Privacidade do JARVIS

Última atualização: 29/10/2026

O JARVIS é um assistente pessoal de uso privado, operado pelo próprio dono da conta Google que o autoriza.

Dados acessados

Com a autorização do usuário, o JARVIS acessa Google Agenda, Gmail, Google Drive, Documentos, Planilhas e Contatos somente para executar tarefas pedidas pelo próprio usuário (por exemplo: consultar compromissos, ler ou enviar e-mails, abrir arquivos).

Uso e armazenamento

Os dados são processados no computador do próprio usuário. Não são vendidos, compartilhados com terceiros nem usados para publicidade. O token de acesso fica guardado apenas nesse computador.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
